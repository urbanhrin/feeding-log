# 수유 기록

아기 수유 시각과 양만 간단히 기록하는 안드로이드 앱. 인터넷 권한이 없고, 기록은 휴대폰 안에만 저장된다.

## 설치

1. 이 저장소의 **Releases**에서 최신 `feeding-log.apk`를 휴대폰으로 받는다.
2. 받은 파일을 열고, "출처를 알 수 없는 앱 설치"를 허용한다.
3. 처음 실행할 때 **알림을 허용**한다. 그러면 상시 알림이 생긴다.
4. 잠금화면에서 알림 버튼이 안 보이면, 휴대폰 설정에서 잠금화면 알림을 '상세히' 보이게 바꾼다.

코드를 고쳐서 `main`에 올리면 GitHub Actions가 새 APK를 자동으로 만든다. 같은 키로 서명하므로 기존 앱 위에 덮어 설치하면 기록이 유지된다. (앱을 지웠다 다시 깔면 기록도 사라진다.)

## 동작

- 상시 알림에 분유 / 이유식 / 유아식 버튼. 어떤 버튼을 보일지는 설정에서 고른다(최소 하나).
- 버튼을 누르면 **그 시각으로 바로 기록**되고 양 입력 창이 뜬다. 양은 선택이며, 5초 동안 손대지 않으면 양 없이 닫힌다.
- 단위: 분유 ml, 이유식·유아식 g. 빠른 선택 5개 값은 설정에서 바꾼다.
- 알림에는 마지막 수유 시각과, 그 뒤로 지난 시간이 계속 흘러가며 표시된다.
- 앱을 열면 날짜별 기록. 항목을 누르면 메모 · 양 · 시간을 고치거나 지울 수 있다.
- 시간 수정에서 지금보다 늦은 시각을 고르면 전날로 본다(자정 넘어 고칠 때).
- 알림을 밀어서 지워도 다시 뜨고, 재부팅 뒤에도 다시 뜬다.

기록 파일: 앱 전용 폴더의 `feeds.json` (`Repo.kt`). 화면 색은 `Ui.kt`의 `C`.
